Download for Linux.

Free, for x86-64: Ubuntu 24.04 or newer, Debian, and other distributions.

Ubuntu and Debian Recommended
.deb package
Download .deb
Then install it from your Downloads folder:
sudo apt install ./runbook-amd64.deb
Other Linux
.AppImage, no install needed
Download .AppImage
Make it executable, then run it:
chmod +x runbook-x86_64.AppImage && ./runbook-x86_64.AppImage
